# **App Name**: Revival Meetings Hub

## Core Features:

- Media Upload: Upload images and videos via URL, local storage, or Google Drive.
- CRUD Operations: Enable create, read, update, and delete operations for media items.
- Media Display: Display media items in a grid or list format with titles and descriptions.
- Detailed View: Implement a 'Read More' button to enlarge images/videos and show detailed descriptions.
- Contact Details: Display contact information at the bottom of the website.
- Footer Update: Include the provided footer with contact information and credits.

## Style Guidelines:

- Primary color: Deep Blue (#3F51B5) to evoke a sense of trust and reliability, and reflect a spiritual tone.
- Background color: Very Light Gray (#F0F0F5), close in hue to the primary color, to maintain visual cohesion while ensuring readability.
- Accent color: Gold (#FFD700) to highlight key elements and calls to action, drawing inspiration from themes of enlightenment and significance.
- Headline font: 'Playfair', a serif font known for elegance, adding an element of high design to this content
- Body font: 'PT Sans', a clear, readable sans-serif to support the serif headline, while not appearing overly corporate or stuffy
- Use simple, clear icons to represent different media types and actions.
- Maintain a clean and organized layout with clear sections for media display, descriptions, and contact information.
