# Revival Meetings Hub

A platform to find, share, and experience revival meetings through community-uploaded images and videos.

## Features
- **Browse Media**: View a gallery of powerful moments from revival services.
- **Upload Media**: Share your own images or YouTube videos with the community.
- **Responsive Design**: Built with Next.js and Tailwind CSS for a seamless experience on all devices.
- **AI-Powered**: Integrated with Google Gemini for enhanced features.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS & Shadcn UI
- **AI Platform**: Genkit with Google AI
- **Icons**: Lucide React

## Getting Started
To run the project locally:
1. Clone the repository: `git clone https://github.com/r-karra/Revival-Meetings-Hub.git`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
